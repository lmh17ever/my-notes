Без глубокого погружения — только необходимый фундамент.

- **IP-адреса** — адреса узлов сети;
- **порты** — номер «входа» на узле;
- **клиент и сервер** — кто инициирует запрос, кто обслуживает;
- **DNS** — домен → IP, зачем нужен.

## TCP

- соединение;
- надёжная доставка (подтверждения ACK);
- порядок пакетов;
- обнаружение потерь;
- **handshake** (установление соединения).

## UDP

- отличие от TCP (без гарантии доставки и порядка);
- где используется.

Концептуально важно: **TCP connection может использоваться для нескольких HTTP-запросов** (keep-alive), поэтому HTTP request выполняется поверх соединения.
