## `du -sh /* 2>/dev/null | sort -hr`

Показать, сколько места занимает каждый объект в `/`, от большего к меньшему.

- `du` — Disk Usage;
- `-s` — итоговый размер объекта (не содержимое);
- `-h` — human-readable (`1.2G`, `450M`);
- `/*` — glob: всё, что непосредственно внутри `/`;
- `2>/dev/null` — перенаправление stderr (ошибки не показывать; `/proc`, `/sys` их выдают);
- `|` — pipe: передать stdout одной команды на вход другой;
- `sort -h` — понимать human-readable размеры (`10K`, `100M`, `2G`);
- `sort -r` — reverse: сначала самые большие.

Результат: видно, какой каталог — главный потребитель места (например `12G /var`, `8.4G /usr`).

## `find . -xdev -type f | cut -d "/" -f 2 | sort | uniq -c | sort -n`

Считает, сколько обычных файлов в каждом непосредственном подкаталоге текущей директории.

1. `find . -xdev -type f` — все обычные файлы, не переходя на другие ФС;
2. `cut -d "/" -f 2` — оставить второе поле (имя верхней подпапки);
3. `sort` — сгруппировать одинаковые (нужно для uniq, т.к. uniq считает только соседние);
4. `uniq -c` — посчитать повторения (например `3 etc`, `1 home`, `2 var`);
5. `sort -n` — сортировка по числовому значению, а не по тексту.

Применение: найти папку, где «наплодились» файлы (обычно при исчерпании inode).
