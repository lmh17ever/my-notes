## Идея

На сервере лежат версии приложения:

```text
/var/www/app_v1.0/
/var/www/app_v2.0/
```

Веб-сервер смотрит в `/var/www/current/`, которая является **symlink** на нужную версию.

Деплой новой версии без простоя — одна атомарная команда:

```bash
ln -sfn /var/www/app_v2.0 /var/www/current
```

Web-сервер в ту же миллисекунду начинает читать новую версию. Откат при баге — переставить symlink обратно (1 секунда).

## Разбор команды

`ln` — создаёт ссылки. Два типа: hard link (жёсткая) и symlink (символическая).

- `-s` — создать именно символическую ссылку (`current` — не копия, а объект с записанным путём);
- `-f` (force) — если `current` уже существует, удалить и создать новую ссылку;
- `-n` — не следовать за существующей ссылкой, если конечный путь — ссылка на директорию.

Комбинация `-sfn` часто используется для безопасной замены symlink.

Направление:

```text
/var/www/current  ── symlink ──►  /var/www/app_v2.0
```

Проверить:

```bash
ls -l /var/www/current
```
