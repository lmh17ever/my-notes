В Embedded написать что-то «первым в мире» почти невозможно — железо стандартизировано годами. Но Rust даёт уникальный исторический шанс: сейчас индустрия массово переписывает инфраструктуру на Rust. Ошибка с памятью на сайте — падение сервера, который Docker перезапустит; ошибка с памятью в кардиостимуляторе или тормозах — катастрофа. Rust (Borrow Checker) гарантирует безопасность памяти на уровне микросхем. Поэтому даже качественный порт задачи с C на Rust будет востребован.

Для проектов понадобится недорогая отладочная плата: **STM32** (ARM Cortex-M) или **ESP32** (самый популярный для умного дома).

## Идея 1. Драйвер для редкого или нового датчика

Инженерам при подключении нового дисплея/датчика нужна библиотека-драйвер, общающаяся по I2C/SPI/UART.

- Что делать: купить интересный датчик, открыть Datasheet, разобрать, какими байтами он обменивается, написать чистый crate по стандарту `embedded-hal`.
- Польза: если вашего драйвера ещё нет на crates.io — вы реально первый, кто туда добавил его; инженеры будут скачивать код через `cargo add`.

## Идея 2. Автономный Bluetooth-шлюз для вашей CRM

Связать веб-приложение с физическим миром.

- Что делать: ESP32 с Wi-Fi и Bluetooth, прошивка на Rust, которая сканирует BLE-метки (маячки на ключах/товарах/машинах в CRM) и раз в минуту отправляет JSON-отчёт по HTTP POST в Django REST API.
- Польза: законченное IoT-решение — связываете датчики, микроконтроллеры, сеть, бэкенд и фронтенд.

## Идея 3. Мини-бортовой компьютер для автомобиля (OBD-II сканер)

CRM связана с автомобилями, тема ляжет идеально.

- Что делать: в автомобилях есть разъём OBD-II; дешёвые чипы (ELM327) читают обороты, температуру, ошибки, скорость. Прошивка на Rust для платы с экранчиком, которая считывает параметры и выводит на дисплей.
- Польза: автомобильная электроника даёт вау-эффект; в Rust-сообществе любят протокол CAN-bus.

## Специфика Embedded для резюме

Оценивают: умение читать Datasheet'ы, понимание низкоуровневых интерфейсов (как биты идут по проводам), экономию каждого килобайта RAM (в микроконтроллерах её может быть всего 64 КБ). Требует времени — пусть идеи подождут своего часа на карте развития.
